## About

I'm a software engineer from Pakistan working across **web platforms, applied AI and embedded systems**. I'm most useful where those meet: a NestJS service that has to stay consistent under concurrent writes, an assistant that must answer only from a client's documents, or a dashboard driven by sensors on an ESP8266.

I care about the unglamorous parts that make software trustworthy: transactions, permissions, observability, and deployments that don't take the site down.

## Engineering Highlights

- **Retrieval-augmented assistants** — chunking, self-hosted embeddings and pgvector search, with answers grounded in retrieved sources, LLM tool calls for booking and human handoff, and per-tenant data isolation.
- **Consistency under concurrency** — time-limited reservations and stock updates enforced inside database transactions; escrow payments backed by a double-entry ledger.
- **Real-time at the edges** — Socket.IO messaging and WebRTC calls that still connect on restrictive networks through a self-hosted TURN relay.
- **Architecture that scales with the team** — modular NestJS services, CQRS and hexagonal boundaries, shared typed contracts across a Turborepo monorepo, and RabbitMQ between services.
- **Shipping safely** — Docker and Nginx with health-checked, zero-downtime releases and rollback, automated through GitHub Actions.
