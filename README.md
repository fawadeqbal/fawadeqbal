## 🚀 About Me

I'm a Software Engineer from Pakistan with a background in both **software** and **hardware**. Day to day I build **ERP and e-commerce platforms** with NestJS, Next.js and PostgreSQL. On my own time I build **AI assistants (RAG)**, real-time apps, and **IoT automation** with ESP8266 and Raspberry Pi.

- 💼 **Full Stack Engineer** at Online Dimensions (remote): ERP and e-commerce platforms, microservices over RabbitMQ
- 🤖 Building **RAG assistants** that answer from a business's own documents, with pgvector, LangGraph and LLM tool calling
- 🔌 Connecting software to hardware: smart home and environmental monitoring on ESP8266
- 🧠 Final year project: **liver tumor segmentation** in CT scans with a U-Net in PyTorch (0.955 Dice score)
- 🎓 BS Software Engineering, COMSATS University Islamabad

🔍 I love exploring how things work, whether it's a React app, a Raspberry Pi circuit, or a model detecting tumors in CT scans.
🎯 My goal is to build smart solutions that improve lives, automate processes, and bridge the gap between people and machines.
